# Charter

## Purpose

Provide a reproducible Docker-based local development environment for common runtimes, databases, web servers, and administration tools, optimized for Ubuntu and WSL2.

## Audience and success

The audience is developers who need an isolated local workspace spanning .NET, PHP/Laravel, Node.js, MongoDB, SQL Server, MySQL/MariaDB, PostgreSQL, and supporting web tools. Success means the templates and instructions are clear, safe to evaluate locally, and do not imply a shared or production platform.

## Ownership

GitHub Issues and the personal portfolio Project track changes. Update this document when supported platforms, services, or security assumptions change.
